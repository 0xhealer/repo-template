# repo-template

A minimal starting point for new repositories. Click **Use this template** on GitHub to create a new repo from it.

## What's included

| File | Purpose |
| --- | --- |
| `.editorconfig` | Consistent indentation, line endings and charset across editors |
| `.gitattributes` | Line-ending normalization and binary file handling |
| `.gitignore` | Common OS, editor, environment and build ignores |
| `stylua.toml` | [StyLua](https://github.com/JohnnyMorganz/StyLua) formatter config for Lua |
| `LICENSE` | MIT license |
| `CONTRIBUTING.md`, `SECURITY.md` | Contribution and vulnerability-reporting guidelines |
| `.github/workflows/Update-License-Year.yml` | Bumps the LICENSE copyright year every Jan 1 |
| `.github/dependabot.yml` | Keeps GitHub Actions versions up to date |
| `.github/ISSUE_TEMPLATE/`, `.github/pull_request_template.md` | Issue and PR templates |

## After creating a repo from this template

- Rename the project and edit this README.
- Check the copyright holder in `LICENSE`.
- Trim `.gitignore` and `.gitattributes` to what your project needs.
